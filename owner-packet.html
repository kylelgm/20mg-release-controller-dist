Owner details

A public domain you control, in lowercase, for example approve.example.com. Not .local, not an IP address.

Format: ssh-ed25519 AAAA… or sk-ssh-ed25519@openssh.com AAAA…. Type and base64 only; remove any trailing comment. Public key only.

The network allowed to reach SSH. IPv4 /24 to /32, or IPv6 /64 to /128. Prefer a single address: /32 for IPv4 or /128 for IPv6.

What the install does

  • Every download is checksum-checked automatically before it is used.
  • Downloads are tokenless and come over HTTPS from two sources: a public GitHub release and the official 1Password download site.
  • The original reviewed bundle is reconstructed exactly from those two pieces. If the result does not match, nothing is installed.
  • Import is disabled in this enrollment-only sheet.
  • This page makes no claim that a rehearsal has been run.
